# Bltz MCP

The Bltz46 delivery machine, in your terminal. Works with Codex and Claude Code.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/xotw/bltz-mcp/main/install.sh | bash
```

## Sign in

```bash
node ~/.config/bltz/mcp-server.js login you@yourcompany.com
```

Your Bltz password, the same one as the web app. Nothing shows as you type.

Then restart your agent.

## Check it works

Ask your agent: *"what Zeus machines can I see?"*

You only ever see your own. Everything runs as you.
